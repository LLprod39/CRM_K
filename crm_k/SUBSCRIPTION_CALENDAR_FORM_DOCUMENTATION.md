# Документация компонента SubscriptionCalendarForm

## Обзор

`SubscriptionCalendarForm` - это компонент для создания абониментов (записей на несколько дней) в CRM системе управления занятиями. Компонент предоставляет удобный интерфейс для выбора дат в календаре и настройки параметров занятий.

## Основные возможности

### 🗓️ Календарь с выбором дней
- Интерактивный календарь с возможностью выбора дней кликом
- Визуальная индикация выбранных дней
- Навигация по месяцам
- Поддержка выбора всех дней месяца одной кнопкой

### 👥 Управление учениками и учителями
- Выбор ученика для индивидуальных занятий
- Выбор нескольких учеников для групповых занятий
- Выбор учителя (для администраторов)
- Интеграция с существующими компонентами `StudentSearch` и `UserSelector`

### ⚙️ Настройки занятий
- Установка времени начала занятия
- Выбор продолжительности (30 мин - 2 часа)
- Установка стоимости за занятие
- Добавление заметок и комментариев

### 💰 Статусы оплаты
- **Запланировано** - занятие создается без предоплаты
- **Предоплачено** - занятие создается с предоплатой
- Возможность индивидуальной настройки статуса для каждого дня
- Визуальная индикация статусов в календаре

### 👁️ Предварительный просмотр
- Показ всех создаваемых занятий перед сохранением
- Отображение даты, времени, стоимости и статуса каждого занятия
- Возможность скрыть/показать детали

## Логика работы

### Статусы занятий

Компонент автоматически определяет статус занятия на основе выбранных параметров:

- **Запланировано** (`scheduled`) - если чекбокс "Предоплачено" не отмечен
- **Предоплачено** (`prepaid`) - если чекбокс "Предоплачено" отмечен

### Создание занятий

Для каждого выбранного дня создается отдельное занятие через API `/api/lessons` со следующими параметрами:

```typescript
{
  date: Date,           // Дата и время начала
  endTime: Date,        // Время окончания
  studentId: number,    // ID ученика (для индивидуальных)
  studentIds: number[], // ID учеников (для групповых)
  cost: number,         // Стоимость
  isPaid: boolean,      // Статус оплаты
  isCompleted: false,   // Всегда false для новых занятий
  isCancelled: false,   // Всегда false для новых занятий
  notes: string,        // Заметки
  lessonType: 'individual' | 'group'
}
```

### Валидация

Компонент выполняет следующие проверки:

1. **Выбор ученика** - обязателен для индивидуальных занятий
2. **Выбор учеников** - минимум один для групповых занятий
3. **Выбор учителя** - обязателен для администраторов
4. **Стоимость** - должна быть больше 0
5. **Выбор дат** - минимум один день должен быть выбран

## Интеграция с существующей системой

### Совместимость с ролями

- **ADMIN** - может выбирать любого учителя и любого ученика
- **USER** - может выбирать только своих учеников

### Использование существующих компонентов

- `StudentSearch` - для поиска и выбора учеников
- `UserSelector` - для выбора учителей
- `apiRequest` - для API запросов
- `useAuth` - для получения информации о текущем пользователе

### API интеграция

Компонент использует существующий API endpoint `/api/lessons` для создания занятий. Каждое занятие создается отдельным запросом.
