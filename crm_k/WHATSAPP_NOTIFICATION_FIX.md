# Исправление ошибки WhatsApp уведомлений

## Проблема
При попытке отправить тестовое уведомление возникала ошибка:
```
Error sending test notification: Error: WhatsApp client not ready
```

## Причина
WhatsApp клиент не был инициализирован или не был готов к работе. API возвращал ошибку 400 с сообщением "WhatsApp client not ready".

## Решение

### 1. Улучшена обработка ошибок в тестовом роуте
Файл: `src/app/api/notifications/test/route.ts`

**Изменения:**
- Добавлена проверка статуса WhatsApp клиента перед отправкой сообщения
- Улучшена обработка ошибок с более информативными сообщениями
- Добавлены подсказки для пользователя

**Новая логика:**
1. Проверяем статус WhatsApp клиента через API
2. Если клиент не готов - возвращаем понятную ошибку с инструкциями
3. Если клиент готов - отправляем сообщение
4. Улучшена обработка сетевых ошибок

### 2. Создан скрипт для управления WhatsApp клиентом
Файл: `scripts/init-whatsapp.js`

**Команды:**
```bash
# Проверить статус клиента
node scripts/init-whatsapp.js status

# Инициализировать клиент
node scripts/init-whatsapp.js init
```

### 3. Исправлена ошибка сборки
Файл: `src/infrastructure/database/index.ts`

**Проблема:** Отсутствовал файл `db.ts`, который экспортировался из `index.ts`
**Решение:** Создан адаптер, который реэкспортирует `prisma` из `@/lib/db`

## Как использовать

### Инициализация WhatsApp клиента
1. Запустите сервер разработки
2. Выполните команду:
   ```bash
   node scripts/init-whatsapp.js init
   ```
3. Перейдите в админ-панель для сканирования QR кода
4. После сканирования клиент будет готов к работе

### Проверка статуса
```bash
node scripts/init-whatsapp.js status
```

### Отправка тестовых уведомлений
После инициализации клиента тестовые уведомления будут работать корректно. Если клиент не готов, пользователь получит понятное сообщение об ошибке с инструкциями.

## Структура ответов API

### Успешная отправка
```json
{
  "success": true,
  "message": "Test notification sent successfully"
}
```

### Клиент не готов
```json
{
  "error": "WhatsApp клиент не готов",
  "details": "Необходимо инициализировать WhatsApp клиент перед отправкой сообщений",
  "status": {
    "ready": false,
    "qrCode": "data:image/png;base64,..."
  },
  "suggestion": "Перейдите в админ-панель и инициализируйте WhatsApp клиент"
}
```

### Ошибка сети
```json
{
  "error": "Ошибка подключения к WhatsApp API",
  "details": "Не удается подключиться к серверу WhatsApp",
  "suggestion": "Проверьте, что сервер запущен и доступен"
}
```

## Дополнительные улучшения

1. **Автоматическая проверка статуса** - тестовый роут теперь автоматически проверяет готовность клиента
2. **Информативные ошибки** - все ошибки содержат детальную информацию и подсказки
3. **Удобный скрипт управления** - простые команды для инициализации и проверки статуса
4. **Исправлена сборка** - устранена ошибка с отсутствующим модулем `db.ts`

## Тестирование

1. Убедитесь, что сервер запущен
2. Проверьте статус: `node scripts/init-whatsapp.js status`
3. Если не готов, инициализируйте: `node scripts/init-whatsapp.js init`
4. Отсканируйте QR код в админ-панели
5. Повторите проверку статуса
6. Попробуйте отправить тестовое уведомление
