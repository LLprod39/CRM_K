# Документация страницы "Абонименты"

## Обзор

Новая вкладка "Абонименты" (`/subscriptions`) предоставляет централизованное место для управления занятиями на несколько дней и создания абониментов в CRM системе.

## Что было добавлено

### 🗂️ Новая страница `/subscriptions`
- **Файл**: `src/app/subscriptions/page.tsx`
- **Функции**: Управление абониментами, просмотр статистики, создание новых занятий

### 🧭 Обновленная навигация
- **Десктопная навигация**: `src/components/ui/Navigation.tsx`
- **Мобильная навигация**: `src/components/ui/MobileNavigation.tsx`
- **Манифест**: `public/manifest.json`

## Функциональность страницы

### 📊 Статистика
- **Всего занятий** - общее количество занятий в системе
- **Активные** - количество незавершенных и неотмененных занятий
- **Доход** - общая сумма от оплаченных занятий
- **Предстоящие** - количество занятий в будущем

### 🔍 Фильтрация и поиск
- **Поиск по ученику** - поиск по имени ученика или родителя
- **Фильтр по статусу**:
  - Все статусы
  - Запланировано
  - Предоплачено
  - Проведено
  - Отменено

### 📋 Список занятий
- Отображение всех занятий с детальной информацией
- Цветовая индикация статусов
- Информация об ученике, времени, стоимости
- Данные об учителе (для администраторов)

### ➕ Создание абониментов
- Кнопка "Создать абонимент" открывает `SubscriptionCalendarForm`
- Автоматическое обновление списка после создания
- Интеграция с существующим API

## Интеграция с существующей системой

### 🔗 Используемые компоненты
- `SubscriptionCalendarForm` - форма создания абониментов
- `useAuth` - аутентификация и роли пользователей
- `apiRequest` - API запросы

### 🎨 Дизайн
- Соответствует общему стилю приложения
- Фиолетовая цветовая схема для абониментов
- Адаптивный дизайн для всех устройств
- Градиентные заголовки и карточки

### 🔐 Права доступа
- **ADMIN** - полный доступ ко всем функциям
- **USER** - доступ к своим ученикам и занятиям

## Использование

### Для пользователей
1. Перейти на вкладку "Абонименты" в навигации
2. Просмотреть статистику и список занятий
3. Использовать поиск и фильтры для навигации
4. Нажать "Создать абонимент" для добавления новых занятий

### Для администраторов
- Полный доступ ко всем функциям
- Возможность просматривать занятия всех учителей
- Управление абониментами для любых учеников
