# Исправление: Добавление поля телефона для уведомлений

## Проблема
У пользователей (преподавателей) не было номера телефона для получения уведомлений. Система пыталась отправлять уведомления на `user.email`, что неправильно.

## Решение

### 1. Добавлено поле `phone` в модель User
**Файл:** `prisma/schema.prisma`

```prisma
model User {
  id        Int      @id @default(autoincrement())
  email     String   @unique
  password  String
  name      String
  phone     String?   // Номер телефона для уведомлений
  role      UserRole @default(USER)
  // ...
}
```

**Миграция:** `20250914060144_add_user_phone_field`

### 2. Обновлена логика уведомлений
**Файл:** `src/app/api/notifications/schedule/route.ts`

**Изменения:**
- Заменено `user.email` на `user.phone`
- Добавлена проверка наличия номера телефона
- Пропуск пользователей без номера телефона

**Новая логика:**
```typescript
// Проверяем, есть ли номер телефона у пользователя
if (!user.phone) {
  console.log(`Пользователь ${user.name} не имеет номера телефона для ежедневной сводки`);
  continue;
}

// Создаем запланированное уведомление
await prisma.scheduledNotification.create({
  data: {
    userId: user.id,
    phoneNumber: user.phone, // Используем phone вместо email
    message: message,
    scheduledTime: summaryTime,
    notificationType: 'daily_summary'
  }
});
```

### 3. Добавлено поле телефона в интерфейс
**Файл:** `src/components/admin/AddUserModal.tsx`

**Изменения:**
- Добавлено поле "Номер телефона (для уведомлений)"
- Поле необязательное (не required)
- Подсказка о назначении поля
- Иконка телефона

### 4. Обновлены API роуты
**Файлы:** 
- `src/app/api/admin/users/route.ts` (POST, GET)
- `src/app/api/admin/users/[id]/route.ts` (PUT)

**Изменения:**
- Поддержка поля `phone` в создании пользователя
- Поддержка поля `phone` в обновлении пользователя
- Возврат поля `phone` в ответах API

### 5. Обновлены типы TypeScript
**Файл:** `src/app/admin/page.tsx`

**Изменения:**
- Добавлено поле `phone?: string` в интерфейс `handleUserSubmit`

## Как использовать

### 1. Добавление номера телефона пользователю
1. Перейдите в **Админ-панель → Пользователи**
2. Нажмите **"Добавить пользователя"** или **"Редактировать"**
3. Заполните поле **"Номер телефона (для уведомлений)"**
4. Сохраните изменения

### 2. Формат номера телефона
- Рекомендуемый формат: `+7 (999) 123-45-67`
- Система автоматически очистит символы при отправке
- Номер должен быть в международном формате

### 3. Проверка работы уведомлений
1. Убедитесь, что у пользователя есть номер телефона
2. Включите уведомления в настройках
3. Создайте тестовое уведомление
4. Проверьте статус в разделе "Запланированные"

## Логика работы

### Ежедневные сводки
1. Worker проверяет пользователей с включенными ежедневными сводками
2. Если у пользователя нет номера телефона - пропускает его
3. Если номер есть - создает уведомление на указанное время

### Еженедельные сводки
1. Worker проверяет пользователей с включенными еженедельными сводками
2. Если у пользователя нет номера телефона - пропускает его
3. Если номер есть - создает уведомление на выбранный день недели

### Напоминания о занятиях
- Отправляются на номер телефона родителей ученика (из поля `student.phone`)
- Не зависят от номера телефона преподавателя

