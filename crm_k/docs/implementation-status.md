# Статус внедрения экстрактора WhatsApp → CRM

## Выполнено
- Добавлены сущности Prisma для черновиков, версий, сообщений, логов и конфигурации экстрактора (`conversation_drafts`, `draft_versions`, `draft_submissions`, `conversation_messages`, `extractor_logs`, `extractor_config`).
- Реализованы доменные сервисы и репозитории: `ExtractorService` для применения patch и `ExtractorConfigRepository` для хранения настроек.
- Созданы REST API `/api/extractor` и `/api/admin/extractor-settings` для работы с черновиками и админ-настройками.
- Подготовлены JSON-схемы и утилиты нормализации/валидации данных.
- Добавлен раздел «Extractor settings» в админ-панели.
- Настроена генерация patch через Google GenAI с автоприменением и логированием.
- Реализована конфигурация промптов, температуры и лимита токенов, кэширование и fallback при сбоях LLM (этап 2 завершён).
- `.env` дополнен требуемыми переменными для экстрактора.
- **Этап 3 завершён**: Интеграция WhatsApp с экстрактором полностью реализована, включая автоматическую обработку сообщений, real-time обновления через WebSocket, асинхронную обработку уведомлений и UI для подтверждения данных оператором.
