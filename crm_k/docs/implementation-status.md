# Статус внедрения экстрактора WhatsApp → CRM

## Выполнено
- Добавлены сущности Prismа для черновиков, версий, сообщений, логов и конфигурации экстрактора (`conversation_drafts`, `draft_versions`, `draft_submissions`, `conversation_messages`, `extractor_logs`, `extractor_config`).
- Реализованы репозитории и сервисы доменного слоя: `ExtractorService` для применения patch и `ExtractorConfigRepository` для хранения настроек.
- Создан REST API `/api/extractor` для работы с черновиками и `/api/admin/extractor-settings` для управления конфигурацией.
- Разработаны JSON-схемы форм (запись на урок/регистрация/консультация) и утилиты нормализации/валидации входящих данных.
- Добавлен раздел "Extractor settings" в админ-панели для управления порогами уверенности, авто-коммитом и ключом Google GenAI.
- Настроена генерация patch через Google GenAI из истории диалога с автоматическим применением в ExtractorService.
- Обновлён `.env`, чтобы фиксировать значения по умолчанию для экстрактора и их синхронизацию с UI/репозиторием.
