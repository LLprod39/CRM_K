# 🧪 Тестирование CRM Системы

## 📋 Обзор

Этот набор тестов предназначен для проверки работоспособности всех компонентов CRM системы. Все тесты имеют понятные русские описания и детальные отчеты о результатах.

## 🚀 Быстрый старт

### Установка зависимостей
```bash
cd tests
npm install
```

### Запуск всех тестов
```bash
npm test
```

### Запуск с детальным выводом
```bash
npm run test:detailed
```

## 📊 Типы тестов

### 🔐 Тесты аутентификации (`auth-api.test.js`)
- **Описание**: Проверяет корректность входа пользователей в систему, валидацию паролей и токенов доступа
- **Что тестируется**:
  - ✅ Вход в систему с правильными данными
  - ❌ Блокировка входа с неправильным паролем
  - 🔒 Проверка необходимости аутентификации

### 👥 Тесты пользователей (`users.test.js`)
- **Описание**: Тестирует создание, изменение и удаление пользователей, проверяет права доступа
- **Что тестируется**:
  - 👑 Админ видит всех пользователей
  - 🚫 Обычные пользователи не видят список всех пользователей
  - ➕ Создание нового пользователя
  - ✏️ Изменение данных пользователя
  - 🗑️ Удаление пользователя

### 🎓 Тесты учеников (`students.test.js`)
- **Описание**: Проверяет управление учениками: добавление, редактирование, удаление и поиск
- **Что тестируется**:
  - ➕ Создание нового ученика
  - ✏️ Изменение данных ученика
  - 🗑️ Удаление ученика
  - 👑 Админ видит всех учеников
  - 👤 Обычный пользователь видит только своих учеников

### 📚 Тесты уроков (`lessons.test.js`)
- **Описание**: Тестирует создание уроков, изменение их статуса и управление расписанием
- **Что тестируется**:
  - ➕ Создание нового урока
  - ✏️ Изменение статуса урока
  - 🗑️ Удаление урока
  - 👑 Админ может изменять любой урок
  - 👨‍🏫 Учитель может изменять свои уроки

### 💰 Тесты платежей (`payments.test.js`)
- **Описание**: Проверяет обработку платежей, расчет балансов и финансовые операции
- **Что тестируется**:
  - ➕ Создание нового платежа
  - ✏️ Изменение платежа
  - 🗑️ Удаление платежа
  - 👑 Админ может создавать платежи за любого ученика
  - 💰 Проверка суммы платежа

### 📊 Тесты финансов (`finances.test.js`)
- **Описание**: Тестирует финансовую отчетность, статистику доходов и расходов
- **Что тестируется**:
  - 📊 Расчет финансовой статистики
  - 📤 Выгрузка финансовых данных
  - 💰 Расчет баланса ученика
  - 💵 Расчет доходов
  - 💳 Расчет предоплаты

### 🍽️ Тесты обеденных перерывов (`lunch-breaks.test.js`)
- **Описание**: Проверяет управление обеденными перерывами и их влияние на расписание
- **Что тестируется**:
  - ➕ Создание обеденного перерыва
  - ✏️ Изменение обеденного перерыва
  - 🗑️ Удаление обеденного перерыва
  - ⏰ Проверка времени обеда
  - ⚠️ Проверка конфликтов времени обеда

### 🔄 Тесты рабочих процессов (`workflow.test.js`)
- **Описание**: Тестирует полные рабочие процессы от создания ученика до завершения уроков
- **Что тестируется**:
  - 🔄 Полный рабочий процесс
  - 👶 Полный жизненный цикл ученика
  - 💰 Полный финансовый процесс
  - 👑 Полный процесс администратора
  - 🔒 Изоляция данных между пользователями

### 🌐 E2E тесты (`app.test.js`)
- **Описание**: Комплексное тестирование всего приложения в реальных условиях использования
- **Что тестируется**:
  - 🔐 Полный процесс входа в систему
  - ⚠️ Обработка ошибок входа
  - 📊 Загрузка данных для авторизованного пользователя
  - 👑 Разные данные для админа и обычного пользователя
  - 👤 Полные операции с учениками
  - 💰 Обработка платежей и отметка уроков

## 🔧 Решение проблем

### Частые ошибки и их решения

#### 🔐 Проблемы с аутентификацией
- **Ошибка**: "Требуется аутентификация"
- **Решение**: Проверьте правильность логина и пароля

#### 🗄️ Проблемы с базой данных
- **Ошибка**: "Ошибка подключения к базе данных"
- **Решение**: Убедитесь, что база данных запущена и доступна

#### 📧 Проблемы с валидацией
- **Ошибка**: "Неверный формат email"
- **Решение**: Проверьте правильность заполнения всех полей

#### 🔒 Проблемы с правами доступа
- **Ошибка**: "Доступ запрещен"
- **Решение**: Обратитесь к администратору для получения прав

## 📝 Добавление новых тестов

### Структура теста
```javascript
describe('Название группы тестов', () => {
  it('должен делать что-то конкретное', async () => {
    // Подготовка данных
    const testData = { /* данные для теста */ }
    
    // Выполнение действия
    const result = await someFunction(testData)
    
    // Проверка результата
    expect(result).toBe(expectedValue)
  })
})
```

### Рекомендации
- Используйте понятные описания на русском языке
- Группируйте связанные тесты в `describe` блоки
- Очищайте данные после каждого теста
- Проверяйте как успешные, так и ошибочные сценарии
