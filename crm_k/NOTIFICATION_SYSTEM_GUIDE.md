# 📱 Система уведомлений CRM_K

## Описание

Автоматическая система уведомлений через WhatsApp для напоминаний о занятиях и отправки сводок.

## Возможности

### 🔔 Напоминания о занятиях
- Автоматические напоминания за N минут до занятия
- Настраиваемые шаблоны сообщений
- Отправка на номер телефона родителей

### 📊 Ежедневные сводки
- Статистика проведенных занятий за день
- Информация о запланированных занятиях на завтра
- Доход за день

### 📈 Еженедельные сводки
- Статистика за неделю
- Общий доход и количество занятий
- Настраиваемый день и время отправки

## Настройка

### 1. База данных

Система автоматически создает необходимые таблицы:
- `notification_settings` - настройки уведомлений пользователя
- `scheduled_notifications` - запланированные уведомления

### 2. Переменные окружения

Добавьте в `.env`:

```bash
# Токен для защиты worker API
NOTIFICATION_WORKER_TOKEN=your-secure-token-here

# Базовый URL приложения
NEXT_PUBLIC_BASE_URL=http://localhost:3000
```

### 3. Настройка Cron Job

Для автоматической отправки уведомлений настройте cron job:

```bash
# Редактируем crontab
crontab -e

# Добавляем задачу (каждые 5 минут)
*/5 * * * * cd /path/to/crm_k && node scripts/notification-worker.js >> /var/log/notifications.log 2>&1
```

Альтернативно, для разработки можно запускать вручную:

```bash
cd crm_k
node scripts/notification-worker.js
```

### 4. WhatsApp API

Убедитесь, что WhatsApp API подключен и работает:
1. Перейдите в админ панель → вкладка "WhatsApp"
2. Подключитесь к WhatsApp (отсканируйте QR-код)
3. Проверьте статус подключения

## Использование

### 1. Настройка уведомлений

1. Войдите в админ панель как администратор
2. Перейдите на вкладку "Уведомления"
3. Настройте параметры:
   - Включите/отключите уведомления
   - Установите время напоминания (15 мин - 1 день)
   - Настройте ежедневные/еженедельные сводки
   - Отредактируйте шаблоны сообщений

### 2. Шаблоны сообщений

#### Доступные переменные для напоминаний:
- `{minutes}` - количество минут до занятия
- `{studentName}` - имя ученика
- `{time}` - время занятия
- `{location}` - место проведения
- `{teacherName}` - имя преподавателя

#### Доступные переменные для сводок:
- `{date}` - дата
- `{completedLessons}` - количество проведенных занятий
- `{upcomingLessons}` - количество запланированных занятий
- `{dailyRevenue}` - доход за день/неделю

### 3. Автоматическое создание уведомлений

Уведомления создаются автоматически при:
- Создании нового занятия (если уведомления включены)
- Планировании ежедневных сводок
- Планировании еженедельных сводок

### 4. Мониторинг

#### Просмотр запланированных уведомлений:
1. Админ панель → Уведомления → вкладка "Запланированные"
2. Отслеживайте статус отправки
3. Просматривайте ошибки при отправке

#### API для мониторинга:
```bash
# Статистика worker'а за последние 7 дней
GET /api/notifications/worker?days=7

# Запуск worker'а вручную (требует токен)
POST /api/notifications/worker
Authorization: Bearer your-worker-token
```

## Устранение неисправностей

### Уведомления не отправляются

1. **Проверьте WhatsApp подключение:**
   ```bash
   curl http://localhost:3000/api/whatsapp?action=status
   ```

2. **Проверьте cron job:**
   ```bash
   # Список активных задач
   crontab -l
   
   # Проверьте логи
   tail -f /var/log/notifications.log
   ```

3. **Проверьте настройки пользователя:**
   - Уведомления включены
   - Время напоминания корректно
   - Номера телефонов в правильном формате

### Worker не запускается

1. **Проверьте переменные окружения:**
   ```bash
   echo $NOTIFICATION_WORKER_TOKEN
   echo $NEXT_PUBLIC_BASE_URL
   ```

2. **Запустите worker вручную:**
   ```bash
   cd crm_k
   node scripts/notification-worker.js
   ```

3. **Проверьте права доступа:**
   ```bash
   chmod +x scripts/notification-worker.js
   ```

### Ошибки отправки WhatsApp

1. **Проверьте формат номеров телефонов:**
   - Должны быть в международном формате
   - Например: +77071234567

2. **Проверьте статус WhatsApp клиента:**
   ```bash
   curl http://localhost:3000/api/whatsapp?action=status
   ```

3. **Переподключите WhatsApp при необходимости**

## API Endpoints

### Настройки уведомлений
- `GET /api/notifications/settings` - получить настройки
- `POST /api/notifications/settings` - сохранить настройки

### Запланированные уведомления
- `GET /api/notifications/scheduled` - список уведомлений
- `DELETE /api/notifications/scheduled/[id]` - удалить уведомление

### Создание уведомлений
- `POST /api/notifications/schedule` - создать уведомление для занятия
- `PUT /api/notifications/schedule` - планировать сводки

### Тестирование
- `POST /api/notifications/test` - отправить тестовое уведомление

### Worker
- `POST /api/notifications/worker` - обработать уведомления
- `GET /api/notifications/worker` - статистика worker'а

## Безопасность

1. **Токен worker'а** - используйте надежный токен для защиты API
2. **Авторизация** - все API требуют аутентификации пользователя
3. **Валидация данных** - все входные данные проверяются
4. **Логирование** - все действия записываются в логи

## Производительность

- Worker обрабатывает до 100 уведомлений за раз
- Автоматическая очистка старых отправленных уведомлений
- Кэширование настроек пользователей
- Асинхронная отправка сообщений

## Масштабирование

Для больших нагрузок рассмотрите:
1. **Redis Queue** - для очереди уведомлений
2. **Separate Worker Service** - отдельный сервис для обработки
3. **Database Optimization** - индексы для быстрых запросов
4. **Rate Limiting** - ограничение частоты отправки
