# 📱 WhatsApp Web Интеграция - Руководство пользователя

## Обзор

Полноценная интеграция WhatsApp Web в админ панель позволяет вам:
- 💬 Общаться с клиентами прямо из CRM
- 📋 Просматривать все ваши чаты WhatsApp
- 🔄 Синхронизировать сообщения в реальном времени
- 👥 Работать с группами и личными чатами
- 📊 Отслеживать статистику сообщений

## 🚀 Как начать использовать

### 1. Подключение к WhatsApp

1. **Войдите в админ панель** вашей CRM системы
2. **Перейдите на вкладку "WhatsApp"** в главном меню
3. **Нажмите "Подключиться к WhatsApp"**
4. **Отсканируйте QR-код** с помощью WhatsApp на телефоне:
   - Откройте WhatsApp на телефоне
   - Перейдите в Настройки → Связанные устройства
   - Нажмите "Связать устройство" 
   - Отсканируйте QR-код камерой

### 2. Работа с чатами

После подключения вы увидите:

#### Левая панель - Список чатов
- 📱 **Все ваши активные чаты** из WhatsApp
- 🔍 **Поиск по чатам** - найдите нужный разговор
- 👥 **Личные чаты и группы** с соответствующими иконками
- 🔔 **Непрочитанные сообщения** с зелеными бейджами
- 🕐 **Время последнего сообщения**

#### Правая панель - Активный чат
- 💬 **История сообщений** с правильным форматированием
- ✅ **Статусы доставки**: отправляется → отправлено → доставлено → прочитано
- ⌨️ **Поле ввода** с поддержкой Enter для отправки
- 📎 **Кнопки для файлов и эмодзи** (в разработке)

### 3. Отправка сообщений

1. **Выберите чат** из списка слева
2. **Введите сообщение** в поле ввода снизу
3. **Нажмите Enter** или кнопку отправки
4. **Отслеживайте статус** доставки рядом с сообщением

### 4. Создание новых чатов

1. **Нажмите кнопку "+"** в заголовке списка чатов
2. **Введите номер телефона** в международном формате
   - Примеры: `+7 900 123 45 67`, `8 900 123 45 67`, `7 900 123 45 67`
3. **Нажмите "Начать чат"**
4. **Начните общение!**

## 🔄 Синхронизация данных

### Автоматическое обновление
- **Чаты обновляются** каждые 30 секунд
- **Сообщения активного чата** обновляются каждые 10 секунд
- **Статус подключения** проверяется каждые 5 секунд

### Ручная синхронизация
- Нажмите **"Синхронизировать"** для принудительного обновления всех чатов
- Полезно когда нужно сразу увидеть новые сообщения

## 📊 Информация и статистика

В заголовке отображается:
- 🟢 **Статус подключения** (Подключено/Отключено)
- 📱 **Количество активных чатов**
- 📈 **Общее количество чатов** в WhatsApp

## 🎯 Особенности интерфейса

### Типы чатов
- 👤 **Личные чаты** - иконка пользователя, отображается номер телефона
- 👥 **Групповые чаты** - иконка группы, название группы

### Индикаторы
- 🔇 **Отключенные уведомления** - значок рядом с названием
- 🟢 **Онлайн статус** - зеленая точка у аватара (если доступно)
- 🔴 **Непрочитанные сообщения** - красный бейдж с количеством

### Статусы сообщений
- ⭕ **Отправляется** - серый круг
- ✅ **Отправлено** - одна галочка
- ✅✅ **Доставлено** - две серые галочки  
- ✅✅ **Прочитано** - две синие галочки

## ⚙️ Настройки и управление

### Отключение
- Нажмите **"Отключиться"** в правом верхнем углу
- Подтвердите действие
- Все данные чатов будут очищены из интерфейса

### Переподключение
- При любых проблемах с подключением
- Отключитесь и подключитесь заново
- QR-код обновится автоматически

## 🔧 Технические особенности

### Форматирование номеров
Система автоматически распознает и форматирует:
- **Российские номера**: `8 xxx xxx xx xx` → `+7 xxx xxx xx xx`
- **Международные номера**: `7 xxx xxx xx xx` → `+7 xxx xxx xx xx`
- **Готовые форматы**: `+7 xxx xxx xx xx` остается без изменений

### Производительность
- **Кэширование чатов** для быстрой загрузки
- **Ленивая загрузка сообщений** по мере необходимости
- **Оптимизированные запросы** к WhatsApp API

### Безопасность
- **Локальная аутентификация** через QR-код
- **Сессии WhatsApp** управляются автоматически
- **Данные не сохраняются** на сервере без необходимости

## 🆘 Устранение неполадок

### Чаты не загружаются
1. Проверьте подключение к интернету
2. Убедитесь что WhatsApp активен на телефоне
3. Попробуйте переподключиться
4. Нажмите "Синхронизировать"

### Сообщения не отправляются
1. Проверьте номер телефона получателя
2. Убедитесь в стабильности подключения
3. Попробуйте отправить сообщение из WhatsApp на телефоне

### QR-код не сканируется
1. Обновите страницу
2. Убедитесь что камера телефона работает
3. Попробуйте сканировать с другого расстояния

### Статус "Не подключено"
1. Проверьте что WhatsApp запущен на телефоне
2. Убедитесь что интернет стабилен
3. Попробуйте переподключиться

## 📞 Поддержка

При возникновении проблем:
1. **Проверьте консоль браузера** на наличие ошибок
2. **Попробуйте очистить кэш** браузера
3. **Перезапустите приложение**
4. **Обратитесь к администратору** системы
