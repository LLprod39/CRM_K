# Интеграция Notification Worker в веб-приложение

## ✅ Что было реализовано

### 1. **Сервис NotificationWorkerService** (`src/lib/notification-worker.ts`)
- Автоматический запуск при старте приложения
- Обработка запланированных уведомлений каждые N минут
- Возможность изменения интервала в реальном времени
- Логирование всех операций
- Обработка ошибок

### 2. **API для управления worker'ом** (`src/app/api/notifications/worker-manager/route.ts`)
- `GET` - получение статуса worker'а
- `POST` - запуск worker'а
- `DELETE` - остановка worker'а
- `PUT` - ручная обработка уведомлений или изменение интервала

### 3. **Компонент управления** (`src/components/admin/NotificationWorkerManager.tsx`)
- Отображение статуса worker'а
- Кнопки запуска/остановки
- Ручная обработка уведомлений
- **Настройка интервала** (1-60 минут)
- Автообновление статуса каждые 30 секунд

### 4. **Автоматическая инициализация** (`src/components/NotificationWorkerServerInit.tsx`)
- Worker запускается автоматически при старте приложения
- Интегрирован в главный layout

## 🎛️ Управление интервалом

### Через веб-интерфейс:
1. Перейдите в **Админ панель** → **Уведомления**
2. Найдите блок **Notification Worker**
3. Нажмите кнопку **⚙️** (настройки)
4. Установите желаемый интервал (1-60 минут)
5. Нажмите **Применить**

### Через API:
```bash
curl -X PUT http://localhost:3000/api/notifications/worker-manager \
  -H "Content-Type: application/json" \
  -d '{"intervalMs": 300000}'  # 5 минут
```

## 📊 Рекомендуемые интервалы

| Интервал | Использование | Описание |
|----------|---------------|----------|
| **1-2 минуты** | Активное использование | Для частых уведомлений |
| **5 минут** | Стандартный | Баланс между скоростью и ресурсами |
| **10-15 минут** | Экономия ресурсов | Для редких уведомлений |
| **30-60 минут** | Минимальное использование | Только для критических уведомлений |

## 🔧 Технические детали

### Автоматический перезапуск
При изменении интервала worker автоматически:
1. Останавливается
2. Применяет новый интервал
3. Запускается заново

### Валидация
- Минимальный интервал: 1 минута
- Максимальный интервал: 60 минут
- Проверка на сервере и клиенте

### Логирование
Все операции логируются в консоль:
```
🚀 Запуск Notification Worker Service...
✅ Notification Worker запущен (интервал: 300 секунд)
🔄 Интервал worker'а изменен на 2 минут
⏹️ Notification Worker остановлен
```

## 🧪 Тестирование

Запустите тестовый скрипт:
```bash
node scripts/test-worker-integration.js
```

Скрипт проверит:
- Статус worker'а
- Запуск/остановку
- Изменение интервала
- Ручную обработку уведомлений

## 🎯 Преимущества интеграции

1. **Автоматический запуск** - не нужно настраивать cron jobs
2. **Веб-управление** - удобный интерфейс для админов
3. **Гибкие настройки** - изменение интервала без перезапуска
4. **Мониторинг** - видимость статуса в реальном времени
5. **Безопасность** - только админы могут управлять worker'ом
